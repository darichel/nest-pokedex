## Description

[Nest](https://github.com/nestjs/nest) backend app.

## Clone repository

```bash
$ git clone https://github.com/darichel/nest-pokedex.git
```

## Create new branch for development

```bash
$ git checkout -b develop
```

## Install dependencies

```bash
$ npm install
```

## Install Nest CLI

```bash
$ npm i -g @nestjs/cli
```

## Get up database

```bash
$ docker-compose up -d
```

## Stack
*MongoDB
*Nest
